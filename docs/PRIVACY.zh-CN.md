Pulse 是一款本地运行的 macOS 工具，会像灵动岛一样停留在屏幕顶部，用于展示当前 Mac 的系统状态、应用程序列表、剪贴板历史、备忘和待办、截屏录屏工具、蓝牙设备列表和按需读取的 AI 账户聚合用量。

## Pulse 会读取的数据

Pulse 可能会读取以下本机数据：

- 灵动岛和固定面板显示期间的鼠标位置及显示器可用区域，用于在当前屏幕定位面板；仅在运行内存中使用，不记录、不存储、不上传
- CPU 使用情况
- 内存使用情况
- 磁盘容量与磁盘 I/O 计数
- 网络收发字节计数
- 电池状态
- 热状态
- 系统上次启动时间，用于计算开机时长
- 正在运行进程的名称及其 CPU、内存占用
- 用于显示 App 图标的本机 App bundle 路径
- 标准应用位置中的 App 名称、bundle id、版本和 bundle 路径，以及这些 App 的运行状态，用于显示“应用程序”列表
- 用户主动从“应用程序”模块选择“卸载并清理”时，目标 App bundle 路径以及用户 Library 中常见应用支持文件、容器、偏好设置、缓存、日志、登录代理、保存状态、WebKit 和 HTTP 存储候选路径、文件大小和存在状态，用于生成确认列表
- 用户授予蓝牙权限后，本机蓝牙设备的名称、类型、连接状态、蓝牙地址，以及 macOS 暴露的电量和充电状态字段，用于显示蓝牙设备列表、连接/断开已配对设备、展示可读取的电量和充电状态，并在设备电量过低时显示本机提醒；AirPods 类设备在 macOS 返回对应字段时会分别显示左耳、右耳和盒子电量
- 系统剪贴板变化及其内容，包括文本、链接、文件 URL/路径表示、图片、原始 pasteboard 表示、敏感或临时 marker，以及剪贴板声明或 Pulse 推断的来源 App 信息，用于显示“剪贴板”历史；复制文件时 Pulse 不主动读取或保存文件本体内容
- 用户主动输入到“备忘”模块的备忘文本、待办完成状态、置顶状态、创建时间和更新时间
- 用户主动触发“截屏录屏”模块时，由 macOS 原生截图能力读取全屏、窗口或自定义区域画面，并把截图写入系统剪贴板
- 用户主动从“截屏录屏”模块开始录屏时，由 macOS 原生 ScreenCaptureKit 读取全屏、窗口或自定义区域的视频帧；录屏不采集系统音频或麦克风音频
- 用户打开或刷新“AI 用量”中的 Codex Provider 时，由本机已安装的 Codex CLI App Server 返回的账户套餐类型、各独立额度 bucket 的名称、已用百分比、窗口时长、重置时间、限制状态、点数余额或不限量状态、可用重置点数，以及累计 Token、单日峰值、最长任务时长、当前/最长连续使用天数和按日聚合 Token
- 已连接 Claude Code 时，本机 Pulse 扩展在每轮对话结束后记录的按会话、按日累计 Token 数和最长轮次耗时
- 已连接 Claude Code 或已连接 Codex 提醒时，各会话的状态（运行中、等待你批准或回答、已完成、出错）、等待批准的内置工具名称、工作文件夹名称、轮次耗时，以及运行该会话的 App（终端、编辑器、Claude 或 Codex App）的名称和 bundle ID，用于在灵动岛显示 Agent 提醒；Pulse 还会留意这些 App 的退出（只比对 bundle ID），在 App 退出或会话 3 小时没有任何上报时清除对应会话

系统指标、进程、应用程序列表和蓝牙设备列表只用于显示应用界面，不会上传或用于持久追踪。“应用程序”列表和运行状态只在本机内存中按需刷新，不会写入持久数据库。应用卸载清理扫描只会在用户主动从右键菜单进入确认面板时运行，不会后台扫描；候选项完整路径会显示给用户确认，Pulse 只会把用户勾选的项目交给 macOS 移到系统废纸篓，不会直接永久删除，也不会上传候选路径或文件内容。授予蓝牙权限后，蓝牙设备列表会在 Pulse 运行期间于本机内存中低频刷新，用于保持蓝牙面板和低电量提醒可用；蓝牙面板打开时会提高刷新频率。Pulse 不会保存蓝牙地址、设备序列号、电量历史或充电历史。通知建议层只根据这些本机系统指标和蓝牙电量读数生成磁盘空间、电量、温度、内存压力和蓝牙电量建议；关闭建议面板或单条建议只会在本机偏好设置保存开关和建议 ID，不会保存原始指标历史。用户加入“常用应用”的 App bundle 路径会保存在本机偏好设置中，用于下次打开时恢复常用应用面板。

剪贴板历史默认启用，并在 macOS 允许读取后保存在本机 Application Support 目录中。Pulse 默认不按条目数量自动清理，只按 30 天保留历史；用户可在设置中选择 100、500、1000 或无限制的保留条数，也可选择无限制、7 天、30 天或 90 天的保留时间，并可一键清空。带有 `org.nspasteboard.ConcealedType`、`org.nspasteboard.TransientType`、`org.nspasteboard.AutoGeneratedType`、remote clipboard/source 等 marker 的内容也会记录；这些 marker 不会阻止保存、搜索或复制，只会让界面默认遮罩更敏感的记录。双击剪贴板记录的“直接粘贴”会先把该记录写回系统剪贴板，再通过 macOS 辅助功能权限向当前聚焦位置发送一次粘贴快捷键；Pulse 不读取目标 App 的输入内容、窗口内容或辅助功能树。OCR 默认关闭；开启后，图片文字识别只使用本机 Vision 框架，OCR 文本也只保存在本机历史索引中。

备忘模块只保存用户主动输入的内容。普通备忘和待办会保存在本机 Application Support 目录中的 JSON 文件里，用于下次打开 Pulse 时恢复列表、筛选、搜索、完成状态和置顶状态。复制备忘会把该条文本写入系统剪贴板；如果剪贴板历史开启，这次复制会按现有剪贴板规则进入本机历史。Pulse 不会上传备忘内容，不会同步到 iCloud、日历或提醒事项，也不会为备忘创建通知。展开备忘时，Pulse 在本机识别其中的网址并显示为链接，只在用户点按链接时交给系统默认应用打开，不会预先访问链接或抓取预览。

截图完成后的预览提醒会提供用户主动触发的保存、分享、编辑、图钉和识别文字动作。保存动作只会在用户选择位置后把当前截图写为 PNG 文件；分享动作会把截图交给 macOS 系统分享面板，由用户选择 AirDrop、邮件、信息或其他系统分享目标；编辑动作只会在本机前台悬浮编辑窗口中处理当前截图，可用笔触涂抹马赛克，并叠加矩形、圆形、箭头、画笔和文字；编辑器内的保存、分享和图钉也只作用于当前编辑后的图片，完成后会把编辑后的图片重新写入系统剪贴板，不会上传或自动另存文件；图钉动作只会把当前截图保留在本机前台悬浮窗口中，直到用户关闭该窗口，不会额外上传或写入文件；识别文字动作只使用本机 Vision 框架，识别结果不会上传，也不会自动替换剪贴板内容，只有用户在结果窗口中选择复制文字时才会写入系统剪贴板。用户把截图预览拖到 Finder、聊天窗口或文档时，Pulse 会为这次拖拽提供 PNG 数据，并在系统临时目录准备一个 PNG 文件表示；旧的临时拖拽文件会在后续拖拽时清理。

截屏录屏模块只在用户点击截图或录屏动作、或触发截图或录屏快捷键时运行，首次使用需要授予 macOS“屏幕录制”权限。截图时，Pulse 默认会在调用 macOS 原生 `screencapture` 前临时隐藏自己的灵动岛面板；用户也可在面板底部关闭“隐藏 pulse 界面”，让截图包含 Pulse 本身。截图会写入系统剪贴板；若剪贴板历史处于启用状态，这张截图会作为图片记录进入本机剪贴板历史。录屏开始前，全屏和窗口录屏会先复用原生截图选择器生成一张临时选择截图，只读取系统写入的目标范围元数据后立即删除；自定义区域录屏会显示本机 AppKit 选择层，让未选区域暗下去并保持所选区域原始亮度。自定义区域开始录制后，Pulse 会继续显示一个不接收鼠标事件的本机区域指示层，让未录制区域保持暗化、所选区域保留蓝色边界；Pulse 会从最终录制输出中排除该指示层窗口。随后 Pulse 使用 macOS 原生 ScreenCaptureKit 录制选中的显示器、窗口或区域，并用 AVFoundation 写入 `.mov` 文件。“隐藏 pulse 界面”开启时，Pulse 会在目标选择前短暂隐藏；录制开始后 Pulse island 会恢复显示计时和停止按钮，但 ScreenCaptureKit 会从最终录制输出中排除 Pulse 自身，因此保存后的视频不会显示 Pulse island。录制期间 macOS 显示的系统共享指示由系统控制，Pulse 不会把它写入最终视频。录屏默认会隐藏鼠标指针；用户也可关闭“隐藏鼠标”，让指针出现在录制内容中。录屏会先保存到系统临时目录，停止后进入 island 视频预览；用户可以先用本机播放器预览，再选择保存、分享、关闭或丢弃。只有用户从保存面板选择位置后，Pulse 才会把临时 `.mov` 移动到该位置；关闭、丢弃、替换预览、退出或保存失败时，Pulse 会删除仍未保存的临时录屏文件。Pulse 不会把截图或录屏上传到网络。若权限尚未授予或已被拒绝，Pulse 会请求权限或打开系统隐私设置。

“AI 用量”的 Codex Provider 只在主面板、固定面板打开或用户主动刷新时工作。它会启动本机已安装的 `codex app-server --stdio`，通过其官方 `account/rateLimits/read` 和 `account/usage/read` 接口读取上述账户级聚合数据；任一面板打开期间最多每 5 分钟自动刷新一次，全部关闭后停止轮询。Pulse 依赖 Codex CLI 自己已有的登录状态，不读取 `~/.codex/auth.json`、OAuth token、API key 或钥匙串，也不读取提示词、回复、源码、工具输出或原始会话 JSONL。返回快照只保存在 Pulse 当前运行内存中，不写入数据库、偏好设置或文件；刷新失败时，Pulse 会在界面显示错误并继续保留上次成功快照。运行日志只记录 CLI 路径、进程和协议阶段、窗口/每日 bucket 数量及错误类别，不记录凭据、账户内容或实际 Token 用量值。

Claude Provider 安装本机扩展 `~/.claude/pulse-ai-usage-bridge`（只保存扩展代码与配置，不保存用量）。它通过 Claude Code 官方 Mods API 的 `session.start`、`session.attach` 和 `session.measure` 事件读取订阅的 5h/7 天已用百分比与重置时间，以及本会话最近一次从 API 响应收到这些额度的本机时间，调用本机 Pulse 桥接进程转发这些白名单字段；Pulse 仅在内存中用该时间从多个会话里挑选最新读数，避免旧会话覆盖当前额度；不读取会话内容，不调用模型。为兼容旧版终端，连接时还会读写 `~/.claude/settings.json` 的 `statusLine` 配置，包装并保留原命令；状态栏进程仅解码官方 `rate_limits.five_hour` 与 `rate_limits.seven_day`，其余会话元数据不保存、不转发给 Pulse 主进程，原命令仍接收原输入。断开连接会移除自有扩展并恢复原状态栏；其他设置保留。已连接时，Pulse 每次启动会按当前版本和安装位置重新生成自有扩展文件，仅在内容变化时写入。额度经本机分布式通知传给 Pulse，仅保留在运行内存；不读取 Claude 登录文件、钥匙串、原始会话记录或个人文件，不向 Anthropic 或其他服务额外发送网络请求。Claude 额度随本机用量事件更新，超过 1 小时或已过重置时间时标记过期并保留上次数据；Pulse 无法主动拉取 Claude 订阅额度。主面板与固定面板共用刷新生命周期，任一面板仍打开时继续按需工作，全部关闭后停止定时轮询；本机事件仍可更新内存快照。

已连接时，Pulse 扩展还会通过 Claude Code 官方 Mods API 的 `turn.complete` 事件，在每轮对话结束后读取该轮由 API 报告的四项 Token 计数（输入、输出、缓存读取、缓存写入）和轮次耗时，按“会话 + 日期”把累计值写入本机 `~/.claude/pulse-ai-usage-data/<日期>/<会话 ID>.json`。文件只含当天 Token 总数和最长轮次耗时；不含提示词、回复、工具内容、模型、费用或账户信息。每个会话只写自己的文件。Pulse 打开 AI 用量面板或收到 Claude 用量通知时读取这些文件，在运行内存中汇总显示累计、近 7/30 天、单日峰值、连续使用天数和最长任务；读取时把前天及更早的日期合并进同目录的 `days.json`（每天一条 Token 总数和最长轮次耗时），以便保留连接以来的按日统计。断开连接时删除整个目录；删除前 Pulse 会核对目录只含上述文件，否则不做改动。这些统计只涵盖本机已加载扩展的 Claude Code 会话，不包含 claude.ai 网页版或其他设备的用量，也不会上传。

已连接时，Pulse 扩展还会通过 Claude Code 官方 Mods API 的 `turn.start`、`tool.check`、`tool.call`、`turn.complete` 和 `session.end` 事件，在会话开始一轮、需要你批准工具或回答问题、你作答后继续、一轮结束或会话结束时，调用本机 Pulse 桥接进程转发白名单字段：会话 ID、工作文件夹名称（不含路径）、状态、等待批准的内置工具名称（如 Bash；MCP 等其他工具不带名称）、轮次耗时和事件时间。扩展不读取提示词、回复、工具参数、命令内容、文件内容或 diff。桥接进程会沿自己的父进程链查找第一个普通 App，并读取它的名称和 bundle ID，用于“前往”按钮把该 App 调到前台；找不到时退回 Claude Code 自己的 `CLAUDE_CODE_ENTRYPOINT`（桌面版或 VS Code）。这些数据经本机分布式通知传给 Pulse，只保存在运行内存中，不写入文件或偏好设置，不上传；会话结束、你中断该轮或完成 30 分钟后从内存中移除。Pulse 只用它们显示灵动岛提醒面板、提醒条和等待数量。

在 AI 用量的 Codex 页点“连接提醒”后，Pulse 会在 `~/.codex/hooks.json` 中为 `UserPromptSubmit`、`PermissionRequest`、`PostToolUse`、`Stop`、`Interrupt` 和 `SessionEnd` 各加入一条只运行 Pulse 自身的官方 Codex hook；文件中的其他 hook 和设置保持原样，“断开提醒”只移除 Pulse 加入的条目。按 Codex 的规则，这些 hook 需要你在 Codex 中运行 `/hooks` 信任后才会运行；Pulse 会通过已安装 Codex CLI 的官方 App Server `hooks/list` 接口读取它们的信任状态，以便提示你。Codex 运行 hook 时会把会话 ID、工作目录、事件名、工具名，以及提示词、工具参数和最后一条回复等写入 hook 的标准输入；Pulse 只解码会话 ID、工作目录的文件夹名、事件名和内置工具名称，其余内容不解码、不保存、不转发。hook 不输出任何内容并总是成功退出，因此不会改变 Codex 的审批或运行流程。之后的会话状态处理、宿主 App 识别、内存保存和移除规则与上面的 Claude Code 相同；Pulse 不读取 `~/.codex/auth.json`、钥匙串或原始会话记录。

连接还会将自有扩展目录添加到 Claude 用户设置的 `env.CLAUDE_CODE_PLUGIN_DIRS`。其他环境变量和扩展目录保持原值；断开时仅移除 Pulse 的目录登记。这里保存的是本机加载配置，不包含账户凭据或用量值。

## Pulse 不会收集的数据

Pulse 不会收集、存储或传输：

- 个人文件
- 通讯录、照片、日历或定位数据
- 钥匙串内容；如果用户把密码、验证码、API key 或其他凭据复制到系统剪贴板，剪贴板模块会按历史记录本机保存，并在列表中默认遮罩
- 应用内行为分析数据或功能使用遥测
- 蓝牙地址、设备序列号或持久追踪标识的持久记录或上传
- 备忘内容、待办内容或完成状态的网络上传
- Codex OAuth token、API key、提示词、回复、源码、工具输出或原始会话日志

## 网络使用

Pulse 会通过 HTTPS 请求 TimeLikeSilver 官网的 appcast 文件，用于检查是否存在新版本；当用户点击更新时，Pulse 会下载对应发布包并由 Sparkle 验证签名后安装。

当用户打开或刷新 Codex Provider 时，本机 Codex CLI 会使用它已有的登录状态向 OpenAI 请求账户级聚合用量。OpenAI 会收到完成该请求所需的现有账户身份以及普通网络请求可能包含的 IP 地址、User-Agent、请求时间和请求路径；本机 App Server 也会收到 Pulse 的客户端名称和版本。该请求不由 Pulse 附加系统指标、进程列表、应用程序列表、蓝牙数据、剪贴板、备忘、截图、录屏、个人文件、提示词、回复、源码或工具输出。有关 OpenAI 如何处理其服务数据，请参阅 OpenAI 适用的隐私政策和账户条款。

和普通 HTTPS 请求一样，appcast 请求可能会由服务器处理标准请求元数据，例如 IP 地址、User-Agent、请求时间和请求路径。TimeLikeSilver 可能会将这些请求用于安全、运维和汇总更新检查次数，以了解 Pulse 的运行趋势。更新检查不会附加 CPU、内存、设备型号、系统启动时间、进程列表、应用程序列表、蓝牙设备列表、蓝牙电量、蓝牙充电状态、剪贴板内容、App bundle 路径、文件内容或 Sparkle 系统画像。

## 本地偏好设置

Pulse island 显示期间，Pulse 会通过 macOS 事件监听读取鼠标指针在屏幕上的位置和按键是否按下，仅用于判断指针是否位于岛形面板内，从而让面板接收点击、让面板外的点击继续交给下方的 App。指针位置只在当次判断中使用，不记录、不存储、不上传，也不读取键盘输入；该监听不需要辅助功能权限，面板关闭后即停止。

资源监控和 AI 用量固定面板首次打开时，Pulse 读取鼠标所在屏幕及其可用区域，用于放置面板。选择跨屏跟随时，面板显示期间每 350 毫秒检查一次，以保留相对位置跨屏移动；锁定当前屏幕或关闭面板后停止对应检查。重新启用跟随时会读取面板当前屏幕的可用区域。位置和区域不记录、不持久保存、不上传，也不触发用量请求，不需要新增权限。

Pulse 可能会使用 macOS 本地存储保存语言、外观、开机启动、AI 用量和资源监控面板各自的跨屏跟随开关、应用程序列表显示方式、常用应用 App bundle 路径、通知建议面板开关、已关闭建议 ID、剪贴板 OCR 开关、剪贴板保留数量、剪贴板保留天数、截屏和录屏时是否隐藏 pulse 界面、录屏时是否隐藏鼠标，以及唤醒剪贴板、唤醒应用程序、三种截图模式和三种录屏模式的快捷键等偏好设置。备忘内容保存在本机 Application Support 目录，不写入用户偏好设置。蓝牙设备列表、连接状态、电量和充电状态不会写入本地偏好设置；AI 用量快照及刷新错误也不会写入本地偏好设置或其他持久存储。
