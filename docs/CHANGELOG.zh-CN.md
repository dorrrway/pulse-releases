# 更新日志

完整历史版本记录。README 只展示未发布内容和最新 3 个正式版本。

### 未发布

- Pulse Island 新增 Agent 提醒，不用再盯着 Claude Code 窗口：会话需要你批准工具、回答问题或审阅计划时，灵动岛自动展开成提醒面板，显示项目、所在 App 和等待时长，可点“前往”切回对应的终端、编辑器或 Claude App，也可点“稍后”先收起；任务完成或出错时面板短暂弹出后自动收起，其他正在运行或刚结束的会话折叠列在下面。展开面板时，提醒改为模块上方的一行提醒条，“+N”切换其余条目。有 Agent 会话时，灵动岛收起时不再轮播资源读数，改为显示 Codex 或 Claude 的标志、状态灯、状态（运行中、需要你、已完成、出错）和时长，两家都有时轮流显示，有会话等你时只显示需要你的那家；有需要你、已完成或出错的会话时，鼠标移上去先打开提醒面板，点“全部面板”再进入常规面板，点按灵动岛仍直接打开常规面板。提醒面板还会在分隔线下列出当前的内存、电量等系统提醒，点按进入对应模块，有会话时也不会漏看。所在 App 退出或会话 3 小时没有动静时，提醒自动清除。电量、内存、温度、磁盘等系统提醒也改用同一套样式。支持 Claude Code 桌面版、终端和 VS Code，以及 Codex（在 AI 用量的 Codex 页点“连接提醒”，再在 Codex 中运行 `/hooks` 信任 Pulse 的 hook；面板会提示是否还需信任）；Pulse 只接收会话状态、工作文件夹名称和等待批准的内置工具名称，不读取提示词、回复或命令内容，也不保存。更新后请在已打开的 Claude Code 会话中执行 `/reload-plugins`。

- 备忘面板重新排版，阅读更舒展：行距和留白加大，多行备忘的首行作为标题加粗显示，下面两行为正文摘要。点按一条备忘即可原地展开全文，可直接选中其中的文字复制，网址可点击打开，并在展开处复制、编辑、置顶、在备忘与待办间切换或删除；删除后底栏短暂显示“撤销”。输入框按 ⌘↩ 直接添加待办；编辑框随内容增高至面板可见高度，按 Esc 取消编辑，切换到其他备忘、筛选或关闭面板时自动保存修改。搜索时高亮匹配文字，匹配位置较靠后的备忘会从匹配处开始预览。时间改为今天显示时刻、昨天显示“昨天”、更早显示日期（跨年带年份），展开后显示完整日期时间；置顶、完成或切换类型不再改动备忘的时间和排序。“清理已完成”改为文字按钮，仅在有已完成待办时出现。

- AI 用量新增额度预估：每个额度窗口按本窗口开始以来的平均速度，显示“按当前速度，预计 19:42 用完”或“重置时约用 54%”，窗口刚开始时不预估。Claude 的“Token 活动”现在与 Codex 显示相同的项目：最近上报、近 7/30 天、累计、14 日趋势、单日峰值、连续使用和最长任务，数据来自本机连接以来的 Claude Code 会话，并标明“本机”，不含 claude.ai 网页版和其他设备的用量。统计由 Claude Code 扩展在每轮对话结束后写入 `~/.claude/pulse-ai-usage-data`，只含每天的 Token 总数和最长轮次耗时，不含对话内容，断开连接时一并删除。更新后请在已打开的 Claude Code 会话中执行 `/reload-plugins`。

- AI 用量以品牌色区分 Codex 与 Claude：Claude 使用其标志性的橙色，Codex 使用蓝紫色，标志、选中的标签、额度进度条和 14 日趋势随之着色，固定面板中两家一眼可辨；预计用完的提示改为红色，避免与 Claude 橙色混淆。

- AI 用量中 Codex 显示 OpenAI 标志、Claude 显示 Claude 标志，并统一两家的统计结构：顶部“账户额度”分两行显示 5 小时和 7 天窗口的已用比例、剩余比例和重置时间，Codex 的模型专属额度单独列入“其他额度”，“Token 活动”在两边位于同一位置；数据源未提供的统计会明确说明，而不是显示为 0。额度按窗口时长命名，不再显示含义因数据源而异的“主窗口 / 次窗口”。同时修复 AI 用量固定面板底部最后一行被截断的问题。

- 优化应用程序、剪贴板和资源监控进程列表的滚动流畅度，首次打开时尤为明显：应用图标改为在后台加载，加载完成后再显示，不再在滚动中卡顿。

- 修复关闭 Pulse Island 通知后面板收起生硬的问题：通知行、下方模块面板和岛形轮廓现在用同一段动画一起收起：通知原地淡出，不再先跳动或滑过顶栏；通知出现或收起时，面板顶部与屏幕之间也不再闪现空白。

- 新增“像素光谱”视觉风格：资源监控、AI 用量等读数改用自绘的方形点阵数字；进度条由像素格组成，格子颜色随刻度位置从青到红渐变，负载越高，亮起的格子越暖；内存和 CPU 占用改为像素饼图，系统状态改用发光的像素状态灯，AI 用量的 14 日趋势改为像素柱。每个模块有自己的识别色，用于选中的标签、面板顶部的光晕，以及开关、筛选和搜索框的选中态；剪贴板记录按文本、链接、图片、文件显示不同颜色的类型徽章；蓝牙电量改为像素电池，颜色随剩余电量变化。

- 采用 macOS 26 的 Liquid Glass 液态玻璃：Pulse Island 展开后的面板、模块标签栏、底部操作按钮、筛选、搜索框、截图预览操作和固定面板背景改用系统原生玻璃材质，随背景内容透出并自动适配“降低透明度”等辅助功能设置。最低系统要求提高到 macOS 26.0。

- 统一 Pulse Island 各模块与固定面板的视觉风格：模块切换改为常驻标签栏，全部模块一眼可见；资源监控改为指标卡片布局；分组、按钮、筛选、搜索框、提示和空状态使用同一套样式，底部操作栏位置一致；剪贴板和备忘的搜索框常驻底栏，备忘计数移入筛选栏，输入框改为可随内容增高的单行；蓝牙设备按“已连接 / 未连接”分组并以紧凑电量显示。截屏录屏保持竖排列表，同样改用分组样式。

- AI 用量和资源监控固定面板新增屏幕控制按钮，可独立切换“跨屏跟随”和“锁定当前屏幕”，并记住各自选择；资源监控的完整和极简面板均可操作。固定面板的屏幕、图钉和缩放按钮集中在一处，仅在鼠标移入时显示，不再常驻底栏。

- 修复更换 Claude 订阅套餐后 AI 用量可能显示旧额度的问题：同时开着多个 Claude Code 会话时，Pulse 按 Claude 实际收到额度的时间采用最新读数，重新打开的旧会话或已过重置时间的读数不再覆盖当前额度。更新后请重启已打开的 Claude Code 会话（或执行 `/reload-plugins`）以加载新版扩展。

- 修复 AI 用量固定面板在多屏幕下不跟随的问题；现在会像资源监控面板一样跟随鼠标所在屏幕，并保留面板的相对位置。

- 修复 Pulse Island 展开、收起和快速反向切换时露出额外背景框的问题，毛玻璃效果与岛形边界同步变化。

- Claude 用量在 Claude Code 空闲时不再很快显示“数据已过期”：仅在超过 1 小时或已过重置时间时才标为过期；mini 面板移除“刚刚更新”“N 分钟前更新”状态。

- 展开后的 Pulse Island 改为一整块连续表面：顶部区域保持纯黑，避免露出菜单栏，下方模块面板与通知建议改为透出并模糊背后内容的深色玻璃材质；开启“降低透明度”时保持原有纯黑样式。展开面板两侧的透明区域不再拦截点击。

- 修复 Claude 桌面版连接后扩展未实际加载的问题；连接时自动补齐加载配置，断开时保留其他扩展设置。

- AI 用量支持切换 Codex 与 Claude，并可固定独立前台面板，同时显示两家的 5 小时和 7 天用量分段条；固定面板采用与资源 mini 面板一致的无标题、无阴影材质样式，仅在鼠标移入面板时显示屏幕控制和图钉按钮，移开后隐藏，锁定屏幕时也不常驻，每条 5h 和 7 天额度条下方显示各自的下次重置时间，当天仅显示时分，其他日期保留月、日和时间。Claude 通过官方 Claude Code 扩展接入桌面、终端和 VS Code；保留原有状态栏并支持断开恢复，未上报或过期时明确提示。

- 修复鼠标移到灵动岛下方的浏览器标签等区域时误展开面板的问题；悬停和点击范围现在与可见岛形边界一致。
- 新增通用“AI 用量”模块，首个 Codex Provider 可独立显示各额度窗口、已用/剩余比例和重置时间，并提供最近上报日、近 7/30 天、累计 Token、14 日趋势、峰值、连续使用和最长任务等账户级聚合指标；数据通过已安装并登录的 Codex CLI 官方 App Server 按需读取，刷新失败时会保留上次成功结果并显示明确错误。
- 修复 Pulse Island 电量显示为 100% 时仍使用非满格电池图标的问题；低电量和充电图标改用系统符号，蓝牙面板的通用电池图标随实际电量分档变化。
- 改善“卸载并清理”的权限说明：确认窗口会先说明为什么需要 App 管理或完全磁盘访问，并提供直接打开系统设置的按钮；纯权限失败时改为简化提醒、警示色授权卡和失败路径列表，授权后可直接重试。
- 剪贴板记录右上角现在会同时显示完整日期和时间，便于区分不同日期保存的内容。

### 2.5.0 - 2026-06-17

- 蓝牙面板现在会在系统蓝牙关闭时显示顶部提醒，并提供开启蓝牙的系统设置入口，避免误显示为没有设备。
- 岛形 header 和主面板之间新增通知建议层，可显示并关闭磁盘空间、电量、温度、内存压力和蓝牙电量建议；多条建议会在同一水平队列中保留一条完整卡片，其余收缩为圆形图标，点击图标会用线性动画在原位置展开并切换到对应面板，也可在设置中整体关闭。
- “应用程序”模块新增右键“卸载并清理”普通确认窗口，可扫描 App bundle 和本机 Library 常见残留路径，用户确认后只把所选项目移到系统废纸篓。
- “卸载并清理”会提前说明 macOS 可能请求 App 管理或其他 App 数据权限；确认流程不再挂在岛形面板内，打开卸载窗口后会收起岛形面板，避免系统授权弹窗被岛形层级遮挡。遇到权限拒绝时会显示中文原因、App 管理和完全磁盘访问入口，并允许授权后只重试失败项。
- 全屏截图和全屏录屏现在先选择目标显示器，多显示器环境下不会再误进入窗口选择；窗口录屏继续使用 macOS 原生窗口选择器。
- 截图编辑器现在会在当前屏幕居中打开，并在进入编辑时收起 island 预览，避免小图被顶部面板遮挡。

### 2.4.0 - 2026-06-03

- 截图模块改为“截屏录屏”，在原有全屏、窗口和自定义区域截图下方新增对应的三种原生录屏入口；全屏和窗口录屏目标选择继续复用 macOS 原生截图选择器，自定义区域录屏使用本机选择层和录制中区域指示层暗化未选区域，实际录制改为 ScreenCaptureKit + AVFoundation 写入 `.mov`。
- 录制开始后 Pulse island 会显示录制计时和停止按钮；开启“隐藏 pulse 界面”时，Pulse 会在目标选择前短暂隐藏，并从最终录屏输出中排除自身；macOS 的系统共享指示由系统控制，Pulse 不会把它写入最终视频。
- 三种录屏模式也可在截屏录屏面板和设置中设置全局快捷键；快捷键会遵循“隐藏 pulse 界面”和“隐藏鼠标”设置，正在录制同一模式时再次触发会停止录制并进入 island 视频预览，用户可先播放确认，再保存、分享、关闭或丢弃临时 `.mov`。
- 截图和视频预览右上角改为关闭按钮，可直接退出预览；从展开面板进入的截图预览关闭后会回到展开状态，关闭视频预览会删除未保存的临时 `.mov`。
- 新增“隐藏 pulse 界面”和“隐藏鼠标”开关：截图前可隐藏 Pulse，录屏输出可排除 Pulse，并可隐藏鼠标指针，便于录制干净的屏幕内容。
- 优化截屏录屏面板图标和模式标题：录屏入口使用独立图标，录屏按钮复用“全屏”“窗口”“自定义区域”模式名称，“隐藏 pulse 界面”使用更清晰的专用图标。
- 新增“备忘”模块，支持在 Pulse island 中通过更大的整行输入栏按回车创建备忘、右键设为待办，并可按全部/备忘/待办/完成筛选、搜索、编辑、置顶、复制、删除和清理已完成待办；所有内容只保存在本机。
- 发布包：[Pulse-2.4.0.dmg](https://github.com/dorrrway/pulse/releases/download/v2.4.0/Pulse-2.4.0.dmg)；SHA-256：`5937825a99e43f2fbf599cd2efb9d871ba16e339bac1b73a504db553c2e3bdae`。

### 2.3.0 - 2026-06-01

- 新增“截图”模块，支持全屏、窗口和自定义区域三种 macOS 原生截图模式；全屏截图会先进入原生屏幕选择并由用户确认，窗口截图会省略系统窗口阴影，截图结果写入系统剪贴板，完成后灵动岛会显示图片预览提醒，未悬停时 3 秒后自动收起，并可在提醒中主动保存、分享、编辑、钉到前台、本机识别文字，或直接把预览图拖到 Finder、聊天窗口和文档；三种模式都可在截图面板中直接设置全局快捷键，快捷键不再强制要求修饰键。
- 截图面板底部新增“截图时隐藏 Pulse”开关，默认开启；关闭后可以把 Pulse 本身截进截图，面板点击和截图快捷键都会遵循该设置。
- 截图完成提醒新增“编辑”入口，会打开类似钉图的前台悬浮编辑窗口，在图片下方提供浅色模式白色、深色模式自适应的图标工具条，最左侧有独立手形移动入口，并支持矩形、圆形、箭头、画笔、马赛克和文字，可直接撤销、保存、分享、钉图、取消或完成。
- 截图编辑器的马赛克改为基于原图像素化的笔触涂抹方式，可沿内容轮廓连续遮挡，不再只能拉出矩形区域。
- 优化截图编辑器文字工具：输入时使用透明且居中对齐的编辑框，点击画布空白区域即可完成输入，已添加的文字可拖动调整位置。
- 钉到前台的截图悬浮窗保持无边框图片窗口样式，并改由 macOS 原生窗口缩放能力按原图比例调整大小。
- 修复截图编辑器默认选中马赛克导致拖动图片时误添加遮挡的问题；现在默认未选择工具，选择工具后图片区域会锁定位置以便准确绘制。
- 修复取消 macOS 原生截图选择后仍显示上一张截图预览的问题；现在只有本次截图确实写入新剪贴板图片时才显示完成提醒。
- 截图面板会在尚未授予 macOS 屏幕录制权限时显示橙色授权提示，说明截图只会在用户点击或触发快捷键时执行。
- 新增“蓝牙”模块，以列表显示本机蓝牙设备、连接状态和可读取的电量；键盘、触控板、鼠标等单电量设备显示一个环状电量，Apple HID 设备在 macOS 返回充电状态时会让电量环中心图标和闪电图标轻量切换，AirPods 类设备在 macOS 返回时分别显示左耳、右耳和盒子电量，并可对已配对设备发起连接或断开。
- 蓝牙设备电量小于等于 20% 或 10% 时，会复用 Pulse Island 的两行提醒样式、颜色和动效显示本机低电量提醒；同一连续低电量状态只提醒一次。
- 优化截图完成提醒的顶部排布，使图标、标题和完成状态与灵动岛顶部区域保持一致。
- 剪贴板记录的右键菜单新增“复制记录”入口，可直接从上下文菜单把记录写回系统剪贴板。
- 修复从“应用程序”模块启动部分 App 后，灵动岛面板刚收起又被过期 hover 事件重新展开的问题。
- 发布包：[Pulse-2.3.0.dmg](https://github.com/dorrrway/pulse/releases/download/v2.3.0/Pulse-2.3.0.dmg)；SHA-256：`66be3ba207946b71e449bf547a963bd4c4bd8f15d780146235958bb405c3efde`。
