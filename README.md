# Pulse

Pulse 是一个停留在屏幕顶部的本机 macOS 控制中心，用灵动岛式入口整合系统状态、常用工具和设备管理。

Pulse is a local-first macOS control center that stays at the top of your screen, bringing system status, everyday tools and device controls into a Dynamic Island-style surface.

## 下载 · Download

- 官网 · Website: [timelikesilver.com/apps/pulse](https://timelikesilver.com/apps/pulse)
- 最新版本 · Latest release: [Releases](https://github.com/dorrrway/pulse-releases/releases/latest)

需要 macOS 26 或更高版本。安装包使用 Developer ID 签名并通过 Apple notarization；已安装的 Pulse 会通过内置更新器自动获取新版本。

Requires macOS 26 or later. Builds are signed with Developer ID and notarized by Apple; installed copies update themselves through the built-in updater.
